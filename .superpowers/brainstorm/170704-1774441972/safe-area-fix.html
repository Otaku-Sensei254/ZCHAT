Fixing Mobile Spacing Discrepancy

Why the padding might not be showing up

The Discovery

I found a few issues that might be preventing our padding from working correctly:

  • Safe Area Inconsistency: The code uses pl-safe and pr-safe, but the Tailwind config only defines a value for "left".
  • Viewport Meta: The viewport meta tag is missing viewport-fit=cover, which is required for safe-area insets to work on many mobile browsers.
  • CSS Precedence: The pl-safe class might be overriding our px-6 if it's resulting in a value of 0.

Proposed Fix (Technical)

Updates to apply
  1. Update root.html.heex to include viewport-fit=cover.
  2. Fix tailwind.config.js to properly define both left and right safe areas.
  3. Switch to standard Tailwind padding or ensure safe areas are added to the padding.
